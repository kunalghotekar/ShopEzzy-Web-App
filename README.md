ShopEzzy – E-Commerce Shopping Application:
Tech Stack: Java, Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Spring Security, Thymeleaf, MySQL, Maven, HTML5, CSS3

Developed a full-stack e-commerce application with secure user authentication, product management, shopping cart, checkout, and order tracking functionalities.

Implemented REST-oriented backend architecture using Spring Boot, Spring MVC, and Spring Data JPA with Hibernate ORM.

Designed and optimized database interactions using MySQL, JPA repositories, and entity relationship mapping.

Built responsive and dynamic user interfaces using Thymeleaf, HTML5, and custom CSS.

Engineered shopping cart and order processing workflows, including quantity updates, total price calculations, and order history management.

Applied layered architecture, dependency injection, and reusable components to enhance maintainability, scalability, and code quality.

Author: Kunal Ghotekar.
